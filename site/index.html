Your agents worked all night. Is anything off?

agentscope renders one scan-first HTML page over your agent crew's scheduled jobs and activity — so you catch silent failures in ten seconds instead of discovering them in logs.

Get it on GitHub See how it works

Python 3.8+ · no dependencies · data never leaves your machine

Why

Observability tools are for debugging traces. You need to supervise a workforce.

LangSmith-class tools assume an ML engineer reading spans. But when your agent crew runs scheduled work around the clock, the human question is simpler — and almost nobody builds for it.

01

Silent failure is the default

Config drift, expired credentials, accidentally disabled jobs — none of these raise their hand. They just quietly stop working.

02

Supervision ≠ operation

The interface inverts: fewer buttons, more signal. agentscope has zero controls. It shows what was already done and whether anything's off.

03

Ten seconds, one page

KPIs up top, problems isolated in one panel, quiet when healthy. If the panel is empty, everything is fine — go make coffee.

Day one

It earned its keep immediately.

"Two production jobs had been silently skipping every run for days. The scheduler noticed a model-config drift and skipped 'to prevent unintended spend' — with no error surfacing anywhere I looked. The dashboard's first render flagged both as FAIL with the exact fix hint. Fixed in two minutes."

What you get

One file in. One file out.

InputYour agent state: job definitions (JSON), execution history (SQLite), session directories. Config-driven — point it at anything.
OutputA single self-contained HTML dashboard. Dark or light theme. Opens on any device.
The panelsKPI row → Needs Attention (anomalies only) → scheduled jobs with ON/OFF → recent actions feed → sessions sparkline.
What it isn'tNot an orchestrator. Not distributed tracing. No multi-user permissions. No buttons at all — read-only by design.
PrivacyReads local files, writes one HTML file. Nothing leaves your machine.
# auto-detects Hermes Agent layout
python3 generate.py -o dashboard.html
