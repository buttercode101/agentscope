The problem

Agent systems fail quietly.

The hard part is often not seeing an error. It is knowing that something that should have happened never did — a scheduled job disabled, credentials rejected, model configuration drifting, or a run failing repeatedly.

01 / SIGNAL

Surface anomalies

Needs Attention is deliberately narrow: disabled jobs, repeated failures, auth failures and known drift patterns instead of a wall of telemetry.

02 / CONTEXT

See what already happened

Recent actions, outcomes, relative timestamps and job health give you enough context to investigate.

03 / SPEED

Scan in seconds

KPIs first. Problems next. Detail after that. When healthy, the interface gets quieter rather than noisier.

What ships

Small surface area. Real utility.

AgentScope reads local state and produces a self-contained supervision view. It is intentionally not another agent control plane.

“The goal is not to watch every token. It is to notice when the work your agents were supposed to do quietly stopped happening.”

— AgentScope product thesis

Under the hood

One file in. One file out.

INPUTJSON job definitions, SQLite execution history, session directories and optional MCP activity.
OUTPUTOne HTML file that works without a runtime, database or hosted service.
PRIVACYLocal by design. The generator reads your files and writes the dashboard locally.
EXTENSIBLEConfigurable sources, anomaly rules, themes, grouping and optional success-rate signals.
python3 generate.py -o dashboard.html

# or point it at your own stack
python3 generate.py --config myconfig.json -o dashboard.html
